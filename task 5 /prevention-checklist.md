#  Stay Safe Online: Prevention Checklist for Indian College Students

##  UPI & Payment Safety (MANDATORY)

| ✓ | Action Item |
|---|-------------|
| ☐ | **Never share UPI PIN** - Not with anyone, for any reason. Banks/Apps NEVER ask for this. |
| ☐ | **Verify before scanning QR codes** - Only scan codes from trusted sources for payments you initiated. |
| ☐ | **Check UPI ID before paying** - Ensure the recipient's name matches who you're paying. |
| ☐ | **Don't click on "KYC update" links** - Always update KYC through official apps only. |
| ☐ | **Set daily transaction limits** - Keep lower limits on your UPI apps. |

##  General Online Safety

| ✓ | Action Item |
|---|-------------|
| ☐ | **Use strong passwords** - Mix of uppercase, lowercase, numbers, special chars. Different for each account. |
| ☐ | **Enable Two-Factor Authentication (2FA)** on all accounts - Especially email, social media, banking. |
| ☐ | **Verify sender before clicking links** - Hover to see real URL; check for spelling errors in emails. |
| ☐ | **Keep devices updated** - Install OS and app updates which contain security patches. |
| ☐ | **Use antivirus software** - Free options like Quick Heal, Avast, or Windows Defender. |
| ☐ | **Log out from public computers** - Always clear browsing data after use in labs/libraries. |
| ☐ | **Think before sharing on social media** - Avoid posting live location, vacation plans, or personal documents. |
| ☐ | **Download apps only from official stores** - Google Play Store or Apple App Store. |

##  If You're a Victim

| ✓ | Immediate Action |
|---|-------------|
| ☐ | **Call Cyber Crime Helpline: 1930** (24x7 toll-free) |
| ☐ | **Report at: cybercrime.gov.in** - National Cyber Crime Reporting Portal |
| ☐ | **Inform your bank immediately** - Block cards/UPI access |
| ☐ | **Save all evidence** - Screenshots, transaction IDs, messages |
